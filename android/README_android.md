# 桌遊推薦 平板 APP 使用說明（給店家）

這個資料夾是店內平板用的「客人挑遊戲」APP。客人在平板上回答幾個小問題，就會看到推薦的桌遊和 YouTube 教學影片；會員輸入手機還能避開玩過的遊戲、領點數。

平板 APP 需要連到櫃檯 Windows 電腦上的伺服器（`start.bat` 啟動的那一個），兩台要在**同一個 Wi-Fi**。

---

## 一、做出 APK 安裝檔（不需要裝任何開發工具）

我們用 GitHub 免費的雲端電腦幫忙編譯。

1. 到 <https://github.com> 註冊帳號（已經有就略過）。
2. 右上角「＋」→ **New repository**，取個名字（例如 `boardgame_recommender`），選 **Private**（私人），按 **Create repository**。
3. 把整個 `boardgame_recommender` 資料夾上傳：
   - 最簡單：安裝 **GitHub Desktop**（<https://desktop.github.com>），File → Add local repository → 選 `boardgame_recommender` 資料夾 → Publish repository。
   - 注意：要上傳的是**整個** `boardgame_recommender` 資料夾，裡面必須同時有 `android` 與 `.github` 兩個資料夾（`.github` 是隱藏資料夾，用 GitHub Desktop 會自動帶上）。
4. 回到 GitHub 網頁上你的專案 → 上方 **Actions** 分頁。
   - 第一次可能要按綠色按鈕「I understand my workflows, go ahead and enable them」。
5. 左邊點 **Android APK** → 右邊 **Run workflow** → 再按綠色 **Run workflow**。
6. 等大約 5～10 分鐘，出現綠色勾勾 ✅ 就完成了（紅色叉叉 ❌ 請看最下方「常見問題」）。
7. 點進那次執行 → 頁面最下方 **Artifacts** → 下載 `boardgame-recommender-apk`（是一個 zip），解壓縮後得到 `app-debug.apk`。

> 之後只要修改 `android` 資料夾裡的檔案並上傳到 GitHub，就會自動重新編譯。

## 二、安裝到平板

> 平板需要 **Android 8.0 以上**（2017 年後的平板幾乎都符合）。

1. 把 `app-debug.apk` 傳到平板（USB 線、Google 雲端硬碟、LINE 傳給自己都可以）。
2. 在平板上點開 APK 檔。
3. 跳出「基於安全性考量，你的平板目前不允許安裝來自這個來源的不明應用程式」→ 點 **設定** → 打開 **允許來自這個來源的應用程式** → 返回 → **安裝**。
4. 如果 Google Play 安全防護跳出警告，選「仍要安裝」（這是你自己編譯的 APP，所以 Google 不認得）。
5. 更新版本時直接安裝新的 APK 即可，設定會保留。

## 三、平板配對（第一次開 APP 會自動進入設定頁）

1. 在櫃檯電腦打開後台網頁 → **平板配對** → **新增裝置**，取個名字（例如「1 號桌平板」）→ 會產生一組**配對碼**。
2. 查櫃檯電腦的 IP：在 Windows 按 `開始` → 輸入 `cmd` → 輸入 `ipconfig` → 找「Wi-Fi」底下的 **IPv4 位址**，例如 `192.168.1.10`。
3. 在平板 APP 的設定頁輸入：
   - **伺服器網址**：`http://192.168.1.10:5000`（只打 `192.168.1.10:5000` 也可以，APP 會自動補上 `http://`）
   - **平板配對碼**：剛剛後台產生的那一組
4. 按 **測試連線**，出現「連線成功！店名：xxx　已配對為：xxx」後，按 **儲存**。

> 之後要再進設定頁：在首頁**長按店名或骰子圖示 5 秒**（客人不會知道這個隱藏入口）。

## 四、把平板鎖定成只能用這個 APP（螢幕固定）

避免客人跳出 APP 去玩別的東西：

1. 平板 **設定** → **安全性**（有些牌子叫「生物辨識和安全性」或「其他安全性設定」）→ **螢幕固定**（或「固定應用程式」/ App pinning）→ 打開。
2. 建議同時打開「**取消固定前要求輸入 PIN 碼**」。
3. 打開桌遊推薦 APP → 按平板下方的「最近使用的 APP」按鈕（方塊鍵，或從底部往上滑停住）→ 點 APP 上方的圖示 → 選 **固定**。
4. 要解除時：同時長按「返回」和「最近使用」按鈕（手勢操作則是從底部往上滑並停住），再輸入 PIN 碼。

APP 本身也做了這些保護：
- 全螢幕、隱藏狀態列與導覽列，螢幕保持常亮。
- 首頁按返回鍵不會關掉 APP；問答中按返回鍵＝回上一題。
- 客人離開 90 秒沒操作會自動回到首頁並清掉會員資料（結果頁 180 秒；看影片時不計時）。

## 五、常見問題

**Q：平板顯示「連不到櫃檯」/ 測試連線失敗**
1. 平板和櫃檯電腦是不是連**同一個 Wi-Fi**？（訪客 Wi-Fi 通常和內部網路隔開，會連不到）
2. 櫃檯電腦的伺服器有沒有開著？（`start.bat` 的黑色視窗不能關）
3. **Windows 防火牆**要允許 5000 port：
   - 第一次啟動伺服器時若跳出「Windows 安全性警訊」，勾選「私人網路」並按「允許存取」。
   - 如果當時按掉了：`開始` → 搜尋「Windows Defender 防火牆」→「進階設定」→「輸入規則」→「新增規則」→ 連接埠 → TCP、特定本機連接埠 `5000` → 允許連線 → 勾選網域/私人 → 取名「桌遊推薦」→ 完成。
   - 也要確認 Wi-Fi 網路類型設為「私人網路」。
4. 先用平板的 Chrome 打開 `http://櫃檯IP:5000`，看得到網頁就代表網路是通的，問題就在網址或配對碼。

**Q：昨天還可以，今天突然連不到**
櫃檯電腦的 IP 可能變了（路由器重開後常會變）。重新用 `ipconfig` 查 IP，到平板設定頁更新。
建議在**路由器後台設定「固定 IP / DHCP 保留」**，把櫃檯電腦綁定一個固定位址，以後就不會再變。

**Q：顯示「平板尚未配對成功」/ 配對碼錯誤**
到後台「平板配對」確認這台裝置還在、配對碼正確（如果在後台刪除或重新產生過，平板要重新輸入）。

**Q：教學影片播不出來**
- 平板需要能連上網際網路（不只是區網）。
- 有些影片作者禁止嵌入播放，按「用 YouTube App 開啟」即可。
- 沒有指定影片的遊戲會開 YouTube 搜尋頁。

**Q：會員頁顯示「操作太頻繁」**
同一台平板每分鐘最多查詢 20 次會員，等一分鐘就好。

**Q：GitHub Actions 出現紅色叉叉 ❌**
點進失敗的那次執行 → 點 **build** → 展開紅色的步驟，把錯誤訊息整段複製下來交給開發助手修正。

**Q：後台改了題目，平板要重新安裝嗎？**
不用。每次客人按「開始挑遊戲」都會向伺服器拿最新的題目與設定。
